### 1.4 Recursion, packs, datapack scripts

`KubeJS.loadScripts(ScriptPack, Path, String)` uses `Files.walk(dir, 10,
FileVisitOption.FOLLOW_LINKS)` — depth **10**, symlinks followed, `.js`/`.ts` accepted,
`.d.ts` excluded (`common/src/main/java/dev/latvian/mods/kubejs/KubeJS.java:173-191`,
filter `:184`).
Only the three top-level folders are special; subfolders are free-form. Scripts in datapacks
and resource packs load from their `kubejs/` folder and take the pack namespace as
`ScriptPack` (`script/ScriptManager.java:96-118`, `new ScriptFileInfo(pack.info,
id.getPath().substring(7))` `:107`).

### 1.5 Header properties and ordering

`common/src/main/java/dev/latvian/mods/kubejs/script/ScriptFileInfo.java:19` defines
`^(\w+)\s*[:=]?\s*(-?\w+)$`; `preload(...)` (`:46-84`) strips blank lines and
`import ` lines, then reads leading `// key: value` comments: `priority` (int,
default 0) `:75`, `ignored`/`ignore` = `"true"` `:76`, `packmode` `:77`,
`requires` (mod ids) `:78`. `skipLoading()` `:99-117` yields `Ignored`,
`Pack mode mismatch`, `Mod X is not loaded`; `ScriptManager.loadFile` logs
`Skipped <location>: <reason>` (1.20.1 `:81-94`).

Ordering is **descending priority** — higher loads first:
`Integer.compare(o.info.getPriority(), info.getPriority())`
(`script/ScriptFile.java:22-24`, byte-identical in 1.20.1). Sorting is per pack
(`ScriptManager.java:148`); packs run in order, each in a child of the shared
top-level scope (`ScriptManager.java:202-205`).

```js
// 1.19.2 + 1.20.1 — server_scripts/base/early.js
// priority: 100
// requires: thermal,create
ServerEvents.recipes(event => { /* runs before lower priorities */ })
```

An empty folder gets a generated `example.js` (`ScriptManager.java:128-137`,
identical text in 1.20.1): `// priority: 0`, a wiki link, then
`console.info('Hello, World! (Loaded startup scripts)')`.

Reloading (generated `README.txt`, `KubeJSPaths.java:97-113`): `startup_scripts` →
`/kubejs reload_startup_scripts`, `server_scripts` → `/reload`, `client_scripts` → `F3+T`,
logs in `logs/kubejs`. Registry objects cannot be created twice — `RegistryInfo.addBuilder`
throws `IllegalArgumentException` on duplicates (`registry/RegistryInfo.java:249`) — so new
items/blocks need a restart.

### 2.3 Gate enforcement and extras

### 2.4 The legacy `onEvent` form throws

```java
event.add("settings", new LegacyCodeHandler("settings"));   // server scripts only
event.add("onEvent", new LegacyCodeHandler("onEvent()"));
event.add("java", new LegacyCodeHandler("java()"));
```

— `BuiltinKubeJSPlugin.java:343`, `:346`, `:347` (1.20.1 `:355-357`, `:359`, `:360`).
Every `call`/`construct`/`put`/`get` in `util/LegacyCodeHandler.java:32-70` throws
the message built at `:26-30`:
`Line <n>: 'onEvent()' is no longer supported! Read more on wiki: https://kubejs.com/kjs6`.
1.20.1 marks it `MutedError` (no stack dump) but still throws.

```js
// 1.19.2 + 1.20.1 — throws at runtime
onEvent('recipes', event => { })

// 1.19.2 + 1.20.1 — correct
ServerEvents.recipes(event => { })
```

Unknown child names do **not** throw: `EventGroupWrapper` logs
`Unknown event '<group>.<child>'!` and returns an empty function (`:19-29`),
`containsKey` being hard-wired `true` (`:32-34`) — a typo is a logged no-op.

### 3.3 `event.recipes.<namespace>.<type>(...)`

`event.recipes` is the map from `getRecipes()` (`RecipesEventJS.java:430`), filled
at `:180-205` with one `NamespaceFunction` per namespace, one `RecipeTypeFunction`
per `"namespace:type"`, camelCase aliases (`UtilsJS.snakeCaseToCamelCase`
`:180-188`, so `crafting_shaped` ≡ `craftingShaped`), `mapRecipe` aliases
(`:190-196`) and the bare aliases `shaped`, `shapeless`, `smelting`, `blasting`,
`smoking`, `campfireCooking`, `stonecutting`, `smithing` (`:198-205`).

So `event.shaped(...)` **is** `event.recipes.kubejs.shaped(...)` — the same function
object. The only difference from vanilla is the serializer: `kubejs:shaped` supports
`kubejs:actions`, `kubejs:modify_result`, `kubejs:stage`, `kubejs:mirror`,
`kubejs:shrink`, degrading to `minecraft:crafting_shaped` when unused
(`ShapedRecipeSchema.java:117-131`; shapeless `:14-26`).

| `settings` | throws (`LegacyCodeHandler`, server only) | `BuiltinKubeJSPlugin.java:343` |

The old string event names, their `event.*` helpers and `settings` are no longer callable; the
symbols remain so the failure is an explicit error rather than `TypeError: onEvent is not a function`.

## 9. Gotchas

1. **Gate mismatch is a registration error** — a server-only listener in `startup_scripts`
   throws `Tried to register event handler '<x>' for invalid script type <type>! Valid script
   types: [...]` (`event/EventHandler.java:110-112`). Startup-gated children include
   `ClientEvents.init` (`bindings/event/ClientEvents.java:18`), `ItemEvents.modification` `:41`,
   `toolTierRegistry` `:42`, `armorTierRegistry` `:43`, `modelProperties` `:53`,
   `BlockEvents.modification` `:41`, `WorldgenEvents.add/remove`.
2. **Startup listeners also receive server/client events** — `post` forwards to
   `ScriptType.STARTUP` (`event/EventHandler.java:265-275`).
3. **`event.shaped` ≡ `event.recipes.kubejs.shaped`**, not "vanilla"; for byte-identical
   vanilla JSON use `event.vanillaShaped` (`RecipesEventJS.java:134`) or
   `event.recipes.minecraft.crafting_shaped` (`ShapedRecipeSchema.java:117-131`).
4. **Argument counts are schema-driven** — a wrong count throws `Constructor for <id> with
   N arguments not found!` (`recipe/RecipeTypeFunction.java:66`): cooking 2–4, shaped 3 or 2,
   others 2 (1.19.2 smithing 3); one JSON object always works (`:58-61`).
5. **Ids are forgiving, enums are not** — `KubeJS.appendModId` (`KubeJS.java:193`) and
   `UtilsJS.getMCID` (`util/UtilsJS.java:412`) default the namespace and tags need `#`, but
   `ItemBuilder.rarity(Rarity)` (`item/ItemBuilder.java:225`), `FluidBuilder.rarity(Rarity)`
   (`fluid/FluidBuilder.java:178`) and `MobEffectBuilder.modifyAttribute(..., Operation)`
   (`misc/MobEffectBuilder.java:41`) need Java enums — no string→enum wrapper exists
   (`BuiltinKubeJSPlugin.java:399-474`); stonecutting counts use `OUTPUT_ID_WITH_COUNT`.
6. **Wrong event names are silent** — `EventGroupWrapper` logs
   `Unknown event '<group>.<child>'!` and returns an empty function (`:19-29`); check
   `logs/kubejs/server.log`.
7. **Registry ids cannot be re-registered** — `RegistryInfo.addBuilder` throws on
   duplicates (`registry/RegistryInfo.java:249`); new items/blocks need a restart.
8. **`serverOnly` changes serializers** — `shaped`/`shapeless` fall back to vanilla (`RecipesEventJS.java:171-172`).
9. **`Text` and `Component` share one wrapper** (`TextWrapper`, bound at 1.19.2 `:352-353`,
   1.20.1 `:374-375`): `{`-leading strings go through `Component.Serializer.fromJson`
   (`bindings/TextWrapper.java:44-51`) plus `{text}` / `{translate, with}` maps (`:55-81`);
   JSON *arrays* are not accepted (the file is identical in both versions).
10. **Datapack scripts are pack-namespaced** (`script/ScriptManager.java:96-118`), so equal relative paths do not collide; `priority` sorts per pack.
11. **Loot and tag changes are server scripts** (`/reload`), not startup (`bindings/event/ServerEvents.java:38-43`).
12. **`event.recipes.<ns>.<type>` is a plain map lookup** — `NamespaceFunction.get(...)`
    returns `map.get(name)` (`recipe/NamespaceFunction.java:26-28`), so an unregistered type is
    `undefined` and calling it raises a JS `TypeError`; use `event.printTypes()` to list ids.
